# Telegram Wildberries Parser Bot

Телеграм-бот с системой подписок, позволяющий находить товары на [wildberries.ru](https://www.wildberries.ru/) по названию и минимальной цене.

## Возможности

- Настройка тарифов подписки (пробный, месячный, годовой) с хранением данных в SQLite.
- Проверка статуса подписки через команду `/status`.
- Подбор товара по названию и минимальной цене через команду `/search`.
- Ответ содержит список ссылок на товары или уведомление, что подходящих товаров не найдено.

## Требования

- Python 3.11+
- Токен телеграм-бота (`TELEGRAM_TOKEN`)

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Создайте файл `.env` и укажите в нём токен бота и при необходимости параметры БД:

```env
TELEGRAM_TOKEN=ВАШ_ТОКЕН
DATABASE_URL=sqlite:///data/bot.db
REQUEST_TIMEOUT=10
MAX_RESULTS=10
```

## Запуск

```bash
python -m bot.main
```

## Использование

1. Вызовите `/subscribe` и выберите подходящий тариф.
2. Убедитесь в наличии активной подписки через `/status`.
3. Используйте `/search` для поиска товаров: бот спросит название и минимальную цену.

## Расширение функционала

- Вы можете добавить собственные тарифы, изменив словарь `DEFAULT_PLANS` в `bot/services/subscription.py`.
- При необходимости реализуйте дополнительные фильтры в `bot/services/wildberries.py`, используя параметры API Wildberries.
